## 🔭 What I'm Working On

### 🤖 STEMSaathi Technologies, Full-Stack Developer *(2026 – Present)*
STEM education company supplying robotics and electronics kits and learning programs to schools. I own the web platform end to end.

- **E-shop** at [stemsaathi.com](https://stemsaathi.com): 164 products with category pages, guest checkout and GST-inclusive pricing
- **Online payments:** built the full ICICI Eazypay integration (secure hash signing, callback handling, automatic order confirmation, success and failure flows)
- **Admin panel:** product import, orders and leads management
- **Backend:** Next.js API, Prisma, PostgreSQL (Neon), Resend emails, spam protection
- **LMS:** courses, modules and lessons, with school accounts and assigned courses, built for school customers
- **SEO:** technical setup, Google Search Console and an on-page and content plan

**Stack:** React · Vite · Next.js · TypeScript · Tailwind CSS · Prisma · PostgreSQL · GSAP · Vercel
